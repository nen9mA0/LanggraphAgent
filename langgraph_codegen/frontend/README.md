# Frontend

This folder contains the Vite + React UI for `langgraph_codegen`.

## What it does

- Flow canvas editing
- LLM and tool registry management
- Python LangGraph code generation preview
- Chatbot sandbox and settings pages

## Default backend

- `http://127.0.0.1:8000`

## Run

From `langgraph_codegen/`:

```bash
npm install
npm run frontend:dev
```
